# 🔍 Achados & Perdidos

Um painel web simples e funcional desenvolvido para facilitar a gestão e a localização de itens perdidos e encontrados em ambientes escolares.

---

## 📌 Sobre o Projeto

O **Achados & Perdidos** foi criado com o objetivo de centralizar as informações de objetos encontrados na escola, permitindo que a comunidade escolar consulte os itens cadastrados e que os responsáveis/administradores registrem novos objetos rapidamente.

🔗 **Acesse o projeto online:** [Achados & Perdidos](https://leonardogroll-commits.github.io/achados-e-perdidos/)

---

## ✨ Funcionalidades

- 📝 **Cadastro de Itens:** Formulário simples para registrar novos objetos encontrados com detalhes como nome, descrição, local onde foi achado e foto.
- 📋 **Listagem de Itens:** Painel visual com todos os itens cadastrados até o momento.
- 📱 **Layout Responsivo:** Acessível tanto em dispositivos móveis quanto em computadores.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica das páginas.
- **CSS3:** Estilização e layout responsivo.
- **JavaScript:** Lógica de manipulação do DOM e gerenciamento dos cadastros.
- **GitHub Pages:** Hospedagem e publicação da aplicação web.
